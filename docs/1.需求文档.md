# 小说阅读网站 — 需求文档

## 一、项目概述

### 1.1 项目定位
一个干净、极简的网络小说在线阅读平台，参考 `book.colafun.com` 的黑白极简风格，专注于阅读体验/线索标注。

### 1.2 端适配范围
本系统分为**前台阅读端**和**后台管理端**两部分，适配范围不同：

| 端 | 适配设备 | 说明 |
|----|---------|------|
| 前台（书架 / 目录 / 阅读） | PC + H5（手机/平板） | 必须完整响应式适配，移动端优先 |
| 后台管理（书籍/章节管理） | 仅 PC | 最小宽度 1024px，无需适配移动端 |

- **前台**：采用移动端优先（Mobile First）策略，PC 和 H5 共用一套代码，通过响应式断点自适应布局
- **后台**：固定 PC 端布局，不考虑移动端访问场景（管理员在电脑上操作）

### 1.3 核心价值
- 简洁纯粹的阅读界面，无广告、无干扰
- 快速加载、翻页流畅，支持线索标注
- 前台 PC / H5 完整响应式自适应

### 1.4 技术栈
| 层级 | 技术选型 | 选型理由 |
|------|---------|---------|
| 前端框架 | Next.js 14 (App Router) | SSR/SSG 支持，路由缓存，SEO 友好 |
| 语言 | TypeScript | 类型安全，开发体验好 |
| 样式 | Tailwind CSS | 原子化 CSS，响应式快捷 |
| 数据库 | Supabase (PostgreSQL) | 开源、免费额度够用、托管省心 |
| ORM | Supabase Client | 直接调用，无需额外 ORM |
| 部署 | Vercel | 与 Next.js 生态无缝集成，CDN 全球加速 |

## 二、功能需求

> **适配说明**：2.1 ~ 2.3 为前台阅读端，必须 PC + H5 双端适配；2.4 为后台管理端，仅 PC 操作。

### 2.1 书架页（首页 `/`）
- **功能描述**：展示所有已收录的书籍
- **核心要素**：
  - 书籍封面（卡片式展示）
  - 书名、作者
  - 搜索框（按书名/作者/标签搜索）
  - 最近阅读的书籍（可选，后续扩展）
- **交互**：点击书籍封面 → 跳转目录页

### 2.2 目录页（`/book/[bookId]`）
- **功能描述**：展示某本书的完整章节目录
- **核心要素**：
  - 书籍信息（书名、作者、字数、章节数）
  - 章节列表（序号 + 章节标题）
  - 章节搜索/筛选（可选）
  - 继续阅读按钮（跳转到上次阅读位置，后续扩展）
- **交互**：点击章节 → 跳转阅读页

### 2.3 阅读页（`/book/[bookId]/[chapterId]`）
- **功能描述**：展示章节正文内容
- **核心要素**：
  - 章节标题
  - 正文内容（支持首行缩进 2 字符）
  - 章节信息（字数、预计阅读时间）
  - 翻页控件（上一章 / 下一章）
  - 字体大小调节（可选）
  - 主题切换（日间/夜间模式，可选）
  - 回到目录按钮
- **交互**：
  - 点击屏幕中间 → 显示/隐藏导航栏
  - 左滑/右滑 → 上一章/下一章
  - 滚动 → 正文内容跟随滚动

### 2.4 后台管理系统（`/admin`）
- **功能描述**：管理员专用后台，用于导入、编辑、管理书籍和章节
- **访问控制**：仅管理员可访问（通过登录验证）

#### 2.4.1 登录页（`/admin/login`）
- **功能描述**：管理员登录
- **核心要素**：
  - 用户名/密码输入
  - 登录按钮
  - 简单的表单验证

#### 2.4.2 仪表盘（`/admin`）
- **功能描述**：后台首页，展示数据概览
- **核心要素**：
  - 书籍总数
  - 章节总数
  - 最近添加的书籍（列表）
  - 快速操作入口

#### 2.4.3 书籍管理（`/admin/books`）
- **功能描述**：管理所有书籍
- **核心要素**：
  - 书籍列表（封面、书名、作者、章节数、操作按钮）
  - 添加书籍按钮
  - 搜索/筛选
  - 编辑书籍信息（书名、作者、封面、简介、状态）
  - 删除书籍（含确认弹窗）
  - 章节管理入口

#### 2.4.4 添加/编辑书籍（`/admin/books/new` 或 `/admin/books/[id]/edit`）
- **功能描述**：新建或编辑书籍基本信息
- **核心要素**：
  - 书名（必填）
  - 作者（必填）
  - 封面上传（支持图片上传或 URL 输入）
  - 简介（选填，textarea）
  - 连载状态（连载中/已完结）
  - 保存按钮

#### 2.4.5 章节管理（`/admin/books/[id]/chapters`）
- **功能描述**：管理某本书的章节
- **核心要素**：
  - 章节列表（序号、标题、字数、操作）
  - 添加章节
  - 编辑章节内容
  - 删除章节
  - 批量导入 TXT 文件
  - 拖拽排序章节

#### 2.4.6 章节编辑器（`/admin/chapters/[id]/edit`）
- **功能描述**：编辑单个章节的标题和正文
- **核心要素**：
  - 章节标题输入
  - 正文内容编辑（textarea，支持大文本）
  - 字数统计（自动计算）
  - 保存按钮
  - 返回章节列表

#### 2.4.7 批量导入（`/admin/books/[id]/import`）
- **功能描述**：从 TXT 文件批量导入章节
- **核心要素**：
  - 文件上传（支持拖拽）
  - 导入预览（解析后显示章节列表）
  - 智能分割（识别"第X章"等章节标题格式）
  - 确认导入按钮
  - 导入进度显示

## 三、UI/UX 设计规范

### 3.1 设计风格
- **基调**：黑白极简，干净纯粹
- **主色调**：深黑背景 `#0a0a0a`（阅读页），白色背景（书架/目录页）
- **强调色**：琥珀金 `#c8a165`（参考站风格，用于封面装饰、按钮高亮）
- **字体**：
  - 正文：系统默认衬线字体优先（宋体/思源宋体）
  - 标题：无衬线字体（黑体/思源黑体）
- **字号**：正文默认 16px（PC）/ 18px（移动端）
- **行高**：正文 1.8 倍
- **首行缩进**：2 字符

### 3.2 响应式断点
| 设备 | 宽度范围 | 布局策略 |
|------|---------|---------|
| 移动端 | < 768px | 单列全宽，触控优化 |
| 平板 | 768px – 1024px | 中等间距布局 |
| 桌面 | > 1024px | 最大宽度限制，居中展示 |

### 3.3 页面状态
- **加载中**：骨架屏 / 简洁 loading
- **空状态**：无书籍 / 无章节 时的友好提示
- **错误状态**：网络异常 / 内容缺失 提示

### 3.4 后台管理系统 UI 规范
- **风格**：简洁后台风格，与前台保持一致的黑白基调
- **布局**：左侧固定导航栏 + 右侧内容区
- **主色**：深蓝/深灰背景，白色文字，琥珀金强调色
- **侧边栏导航**：
  - 仪表盘（首页）
  - 书籍管理
  - 章节管理（子菜单，根据选中书籍动态显示）
  - 批量导入
- **组件规范**：
  - 表格：带排序、分页、操作按钮
  - 表单：标准 label + input 布局，必填项标记
  - 弹窗：确认删除、保存成功等
  - 上传区：拖拽上传 + 点击上传两种模式
- **响应式**：后台以 PC 端为主，最小宽度 1024px

## 四、数据模型设计

### 4.1 表结构

#### 表：`books`（书籍基本信息）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid (PK) | 唯一标识 |
| title | text | 书名 |
| author | text | 作者 |
| cover_url | text | 封面图片 URL |
| description | text | 书籍简介 |
| total_word_count | int | 总字数（冗余，方便展示） |
| status | text | 连载状态（连载中/已完结） |
| created_at | timestamptz | 创建时间 |
| updated_at | timestamptz | 更新时间 |

#### 表：`chapters`（章节目录）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid (PK) | 唯一标识 |
| book_id | uuid (FK → books.id) | 所属书籍 |
| order | int | 排序序号 |
| title | text | 章节标题 |
| word_count | int | 本章字数 |
| created_at | timestamptz | 创建时间 |

#### 表：`chapter_contents`（章节正文）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid (PK) | 唯一标识 |
| chapter_id | uuid (FK → chapters.id, UNIQUE) | 对应章节（一对一） |
| content | text | 正文完整内容 |
| updated_at | timestamptz | 更新时间 |

#### 表：`admin_users`（管理员账号）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid (PK) | 唯一标识 |
| username | text (UNIQUE) | 管理员用户名 |
| password_hash | text | 密码哈希（bcrypt） |
| last_login | timestamptz | 上次登录时间 |
| created_at | timestamptz | 创建时间 |

#### 表：`reading_progress`（阅读进度）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid (PK) | 唯一标识 |
| user_id | text | 用户标识（localStorage key 或用户 ID） |
| book_id | uuid (FK → books.id) | 书籍 ID |
| chapter_id | uuid (FK → chapters.id) | 当前章节 |
| scroll_position | float | 滚动位置（百分比） |
| updated_at | timestamptz | 更新时间 |

### 4.2 设计说明
- **分表策略**：章节目录与正文分离，目录查询无需加载大字段，性能最优
- **索引建议**：`chapters` 表建 `(book_id, order)` 复合索引；`reading_progress` 表建 `(user_id, book_id)` 复合索引
- **数据量估算**：2000 章 × 3000 字 ≈ 6MB 文本，Supabase 免费版 500MB 完全够用
- **封面存储**：封面图片存 Supabase Storage（bucket: `book-covers`），或使用外部 CDN

### 4.3 RLS 策略
- 书籍相关表：`public` 可读（匿名访问），仅管理员可写入
- `admin_users`：仅管理员可读
- `reading_progress`：用户只能读写自己的记录

### 4.4 认证方案
- 管理员使用用户名/密码登录
- 登录成功后签发 JWT Token，存于 httpOnly cookie
- 请求管理 API 时需要携带有效 Token
- Token 有效期：7 天
- 密码使用 bcrypt 哈希存储

## 六、缓存策略

### 6.1 层级设计
1. **浏览器缓存**：静态资源（CSS/JS/封面图）→ `Cache-Control: public, max-age=31536000, immutable`
2. **CDN 缓存**：API 响应 → `Cache-Control: public, s-maxage=31536000`（1 年）
3. **ISR 缓存**：静态页面（书架页/目录页）→ Next.js ISR，`revalidate=86400`（1 天）

### 6.2 策略说明
- 小说内容一旦发布不再变更，适合强缓存
- 阅读页 API 返回头设置长缓存，Vercel CDN 直接返回，不回源到 Supabase
- 目录页用 ISR 预渲染，用户访问时直接命中静态 HTML

## 九、二期规划：小说标注功能

> **背景**：用户看书时常出现"看了后面忘记前面"的问题——角色、伏笔、剧情线索知道存在，但无法快速定位验证。本模块在基础阅读功能完善后开发，提供基于标签的标注与关系图生成能力。

### 9.1 功能目标
- 阅读时可随时为某段文字打上标签，记录位置和备注
- 按标签维度（角色 / 伏笔 / 剧情 / 自定义）快速检索同一标签下的所有标注
- 读完一本书后，基于标注数据自动生成关系图/时间线，辅助回顾全书脉络

### 9.2 标注体系设计

#### 9.2.1 标签（Label）
- **系统预设标签**：角色、伏笔、剧情、地点、物品
- **自定义标签**：用户可新建任意标签，自由命名
- **标签属性**：名称、颜色（用于关系图节点区分）、所属书

#### 9.2.2 标注（Annotation）
一条标注 = 在某本书某章节某位置，挂到某个标签下的一段记录：
- **定位**：书 ID + 章节 ID + 章节内字符偏移量（起止位置）
- **内容**：被选中的原文（快照）、用户备注
- **归属**：标签 ID（一条标注可挂多个标签）
- **元数据**：创建时间、更新时间

#### 9.2.3 关系图（Graph）
基于标注数据自动构建：
- **角色关系图**：以"角色"标签节点为顶点，同章节/相邻章节共同出现 → 连边，边权 = 共现次数
- **剧情时间线**：按章节顺序排列"剧情"标签标注，展示故事发展脉络
- **伏笔追踪**：列出所有"伏笔"标签标注，标记状态（已回收 / 待回收）

### 9.3 用户交互流程

#### 9.3.1 阅读页新增交互
- **选中文字**（PC 鼠标拖选 / H5 长按选择）→ 弹出标注气泡菜单
- 气泡菜单选项：
  - 选择标签（多选，可新建标签）
  - 填写备注（选填）
  - 保存
- 已标注的文字在正文内显示下划线/高亮（按标签颜色着色）
- 点击已标注文字 → 弹出该标注详情，支持编辑/删除

#### 9.3.2 标注侧边栏（阅读页）
- 阅读页右侧/底部抽屉展示当前章节的所有标注列表
- 点击标注 → 跳转到对应位置
- 按标签分组展示

#### 9.3.3 标注总览页（`/book/[bookId]/notes`）
- 展示某本书下所有标注
- 按标签维度切换视图：
  - 标签视图：每个标签下列出所有标注
  - 章节视图：按章节顺序展示
  - 时间视图：按创建时间排序
- 支持搜索、筛选、编辑、删除

#### 9.3.4 关系图页（`/book/[bookId]/graph`）
- **角色关系图**：力导向布局展示角色节点 + 共现关系边
- **剧情时间线**：横向时间轴，节点为"剧情"标注，按章节排列

- 技术选型：关系图使用 `react-force-graph` 或 `d3`，时间线使用 `vis-timeline`

### 9.6 用户体系说明
- 二期标注功能需要用户标识来归属标注数据
- **轻量方案**：未登录用户用 localStorage 生成匿名 user_id，标注数据存在本地 + 可选云端同步
- **完整方案**：接入 Supabase Auth，注册登录后云端存储，跨设备同步
- 建议先做轻量方案验证功能，再迭代到完整用户体系

### 9.7 技术难点与注意事项
1. **字符偏移定位**：正文渲染后字符偏移需稳定，章节内容更新会导致偏移失效，需在内容变更时清理或重新映射旧标注
2. **H5 文本选择**：移动端长按选词交互需用 `Selection API` + 自定义气泡菜单，注意与系统选区菜单冲突
3. **关系图性能**：标注量大时共现计算放后端，前端只渲染，节点数 > 100 时需做聚类或缩略
4. **正文高亮渲染**：在 React 中渲染带高亮的正文需将文本按偏移切分，注意避免 XSS（用 React 文本节点而非 dangerouslySetInnerHTML）
